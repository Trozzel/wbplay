# wbplay
For reuse and editing web based programming

## GitHub Copilot Integration

This repository is configured to work with GitHub Copilot in Neovim. If you have an upgraded GitHub Copilot account (Pro or Enterprise), see [`.github/copilot-instructions.md`](.github/copilot-instructions.md) for setup instructions to ensure Neovim recognizes your upgraded account.

### Quick Setup

1. Open Neovim in this repository
2. Run `:Copilot auth` to authenticate
3. Verify with `:Copilot status`

For troubleshooting and detailed instructions, refer to the [Copilot instructions](.github/copilot-instructions.md).
